# TALLER8_SAMUEL_AYALA
2 ejercicios del taller 8 lógica de programación

# Ejercicio 1
Contexto:
Una empresa tiene tres vendedores que registran las ventas realizadas durante cuatro
semanas.
La información se encuentra organizada en una matriz donde cada fila representa un
vendedor y cada columna representa una semana.
Los valores representan las ventas realizadas en millones de pesos.
