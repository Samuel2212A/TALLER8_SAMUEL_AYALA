# TALLER8_SAMUEL_AYALA
2 ejercicios del taller 8 lógica de programación

# Ejercicio 1
Contexto:
Una empresa tiene tres vendedores que registran las ventas realizadas durante cuatro
semanas.
La información se encuentra organizada en una matriz donde cada fila representa un
vendedor y cada columna representa una semana.
Los valores representan las ventas realizadas en millones de pesos.

# Ejercicio 2
Contexto:
Una universidad ofrece diferentes cursos complementarios para sus estudiantes.
Durante el semestre se registraron los estudiantes inscritos en dos cursos:
Curso A: Fundamentos de programación.
Curso B: Introducción a bases de datos.

Preguntas de análisis
1. ¿Por qué un conjunto es más apropiado que una lista para representar estudiantes
inscritos sin duplicados? RT1: Es más apropiado porque los conjuntos están diseñados para no admitir elementos repetidos.
2. Si un estudiante se inscribe dos veces en el mismo curso, ¿qué sucede con la información almacenada? RT2: La información afectada no cambia, el conjunto solo ignora la información repetida. 
3. ¿Cuál es la diferencia entre la unión y la diferencia simétrica? RT3: La unión agrupa todos los elementos de ambos cursos sin importar si los elementos se repiten, la diferencia simétrica solo agrupa los estudiantes que están en el curso A o en el B pero no incluye a los que están en ambos cursos.
4. ¿En qué situaciones reales sería útil utilizar conjuntos para analizar información? RT4: En situaciones como la gestión de permisos de bases de datos o en redes sociales.
